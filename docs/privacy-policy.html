Image downloader Privacy Policy

Effective date: September 7, 2026

Applies to: Image downloader version 1.2.1 and later

Questions and support are handled through the public GitHub Issues page linked below.

Purpose

Image downloader helps a user identify image resources on the active webpage, preview them, select images, and start downloads. The extension works only after the user invokes it from the browser toolbar.

Information handled

After the user invokes a scan, the extension temporarily reads the active webpage's DOM and image-related resources, including image URLs, responsive image URLs, lazy-loading attributes, CSS background image URLs, image metadata, and image dimensions. The active page URL may also be available to the browser as part of the user-requested tab operation.

The extension stores only the selected interface-language preference in chrome.storage.local. It does not store scanned page content, image pixels, page history, or download URLs in extension storage.

How information is used

Page information is processed locally in the browser to display the floating selection panel, apply filters and sorting, perform the optional deep scan, and start downloads selected by the user. Download requests are made through the browser's Downloads API to the image URLs chosen by the user.

Sharing and servers

The extension does not operate an extension-owned server and does not send page content, image URLs, or language preferences to an extension-owned server. It does not sell data, use data for advertising, use an analytics service, or use an AI service. The browser and the original image host may process network requests according to their own policies and the browser's normal security and referrer behavior.

Retention and control

Scanned page information is kept in memory while the floating panel or page session uses it and is discarded when the panel or page context is closed. The language preference remains in local extension storage until it is changed, removed with the extension, or cleared through browser extension data controls. Download history and downloaded files are controlled by Chrome.

Limitations

Some images cannot be previewed or downloaded because they require authentication, use hotlink protection, have expired URLs, are inside closed Shadow DOM, or exist only as pixels in a Canvas. Browser-internal pages are not supported.

Contact

Changes

When the extension's data handling changes, this policy will be updated before or when the changed version is distributed. The effective date above will be updated with each material change.
