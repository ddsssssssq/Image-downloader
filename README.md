# 网页图片下载器

这是一个无需登录的 Chrome/Edge Manifest V3 浏览器插件（当前版本 1.2.1）。

## 当前功能

- 点击浏览器工具栏图标后，在当前网页右侧打开悬浮面板
- 扫描 `<img>`、`srcset`、懒加载属性、CSS 背景图、SVG、元数据和 Shadow DOM
- 缩略图网格预览
- 全选、取消全选或单独选择图片
- 下载全部图片或下载选中图片
- 自动去重、自动生成文件名，并保存到下载目录下的 `page-images` 文件夹
- 支持跟随浏览器语言，也可手动选择中文、English、日本語、한국어、Español、Français、Deutsch、Português 或 Русский
- 内置工具栏图标
- 支持深度扫描：自动滚动页面以触发懒加载图片
- 支持最小尺寸过滤和按页面顺序、图片尺寸排序
- 批量下载显示启动进度，失败自动重试，并可取消尚未启动的下载

## 安装

1. 打开 Chrome 或 Edge 的扩展程序页面。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录：`image-downloader`。

## 已知限制

- 浏览器内部页面（例如 `chrome://settings`）不能被扫描。
- Blob 图片、需要登录的图片和部分有防盗链的网站可能无法下载。
- 如果浏览器开启了“下载前询问每个文件的保存位置”，批量下载时浏览器可能逐个询问。
- `<canvas>` 中未暴露为图片 URL 的内容不会被识别。
- 扫描时会验证图片 URL 是否能重新加载；无法重新加载的占位 URL 会被过滤，避免列表出现大量“无法预览”卡片。
